# محتوى تطبيق «التقويم الموريتاني»

يقرأ التطبيق هذا الفرع ليحدّث محتواه دون تحديث من المتجر (انظر `apps/calendar-android/README.md` في فرع التطبيق).

- `manifest.json`: رقم إصدار لكل ملف. أي تعديل في ملف يتطلب رفع رقمه هنا، وإلا لن تنزّله الهواتف.
- `c/*.json`: جداول الصفحة (الأماكن، المنازل، القراء، المكتبة، الرعاية…).
- `data/<كتاب>.js` و`img/book-<كتاب>.webp`: الكتب الجديدة وأغلفتها.
- `news`: إشعار للمشتركين برقم جديد (`id`) وعنوان (`t`) ونص (`b`) وصفحة تُفتح (`h`، مثل `#lib`).
