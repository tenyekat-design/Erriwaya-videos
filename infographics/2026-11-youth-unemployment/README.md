# إنفوجرافيك: بطالة الشباب في المغرب العربي (نوفمبر 2026)

فيديو بلا تعليق صوتي (67.6 ثانية) بألوان إنفوجرافيك (خلفية فحمية داكنة ولون ثابت لكل دولة)، مع شعار الرواية وخط القدس
وموقع erriwaya.com (في الرأس وبطاقة العنوان والختام)، وبمقاسين. الموسيقى أصلية مولّدة برمجيا ومتزامنة مع المشاهد
(`make-music.py` → `music.wav`، يُولَّد تلقائيا عند الإخراج إن لم يوجد؛ يتطلب numpy وscipy):

```bash
node infographics/2026-11-youth-unemployment/render.js                 # 1080x1350 فيسبوك
node infographics/2026-11-youth-unemployment/render.js --format story  # 1080x1920 ستوري/ريلز/تيك توك
node infographics/2026-11-youth-unemployment/render.js --stills 9,20   # لقطات للمراجعة
```

المخرجات: `output/erriwaya-infographic-youth-unemployment[-story].mp4` والغلاف `-cover.jpg`.
لا يغيّر شيئا في قالب الموجز: يستعمل `assets/` و`src/map-data.js` و`src/icons.js` كما هي.
