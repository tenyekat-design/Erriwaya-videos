# قالب «كاروسيل» – الرواية

كاروسيل إنستغرام/فيسبوك بقياس 1080×1350، معتمد في 29 أكتوبر 2026 (المرجع: `2026-10-29-minurso/`).

- **الشكل:** خلفية بيضاء، صورة كبيرة أعلى كل شريحة تتلاشى إلى الأبيض، شعار الرواية أبيض أعلى اليسار فوق تدرج داكن خفيف،
  نقاط ترقيم أعلى اليمين، شارة حمراء + عنوان كبير بخط القدس، بطاقات بيضاء بظل خفيف وأيقونات حمراء،
  شريط الحسابات الأبيض في الأسفل (ERRIWAYA / ERRIWAYA.MR) ما عدا الشريحة الأخيرة.
- **أنواع الشرائح في القالب:** غلاف، مكان + رقمان، خلفية ببطاقتين، خط زمني، أرقام، قائمة + رد، مواقف (صورتان + 4 أعلام)، سيناريوهات، ختام.

| الملف | الدور |
|---|---|
| `carousel.css` | التصميم المشترك (لا يتغير لكل كاروسيل) |
| `carousel.js` | الشعار ونقاط الترقيم والتذييل وأزرار الحسابات |
| `_template/carousel.html` | نقطة البداية بنصوص إرشادية |
| `new.js` / `render.js` | إنشاء كاروسيل جديد / إخراج الشرائح PNG |

```bash
node carousels/new.js 2026-11-02-موضوع        # ينسخ القالب إلى carousels/2026-11-02-موضوع/
# ضع الصور في img/ واكتب النصوص في carousel.html (صورة تطابق نص كل شريحة)
node carousels/render.js 2026-11-02-موضوع     # -> carousels/2026-11-02-موضوع/slides/01.png ...
```
